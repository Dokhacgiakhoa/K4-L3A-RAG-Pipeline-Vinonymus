Kiến Trúc RAG Pipeline Đa Tầng (End-to-End)

Chunking & Index
Recursive Splitter, ChromaDB + BM25 Corpus
Hybrid Retrieval
Dense Semantic (Cosine) song song với BM25 Keyword
RRF Reranking
Reciprocal Rank Fusion k=60, chuẩn hóa ID duy nhất
Cosine Fallback
Kiểm tra Score Threshold. Out-of-domain: Safe Refusal
Gemini Generation
Lost-in-the-middle context reorder & Trích dẫn nguồn [1][2]
Quy tắc 1: Đơn nhất RRF
RRF chỉ chạy đúng 1 lần gộp rank, không lặp lại gây méo mó phân phối điểm.
Quy tắc 2: Cosine Score gốc
Fallback kích hoạt dựa trên cosine similarity gốc từ Dense search, tránh false positives.
Quy tắc 3: Contract Tuyệt Đối
Mọi search result tuân thủ nghiêm ngặt Pydantic / TypedDict schema đã test pass.

Giao Diện Next.js Hiện Đại & Công Nghệ PWA

Thay thế hoàn toàn giao diện cơ bản bằng ứng dụng Web hiện đại, có thể cài đặt như Native App trên điện thoại và máy tính.

PWA Installable

Hỗ trợ Service Worker, Web App Manifest, offline shell caching và nút "Cài đặt ứng dụng" trực tiếp trên trình duyệt Chrome, Edge, Safari iOS.

Citation Drawer & Modal

Người dùng nhấp vào từng citation `[1]`, `[2]` để mở popup xem toàn văn đoạn trích gốc, chỉ số điểm tương đồng score và đường dẫn tài liệu.

A/B Testing Control

Công tắc chuyển đổi trực tiếp trên UI giữa chế độ: **Dense-Only Search** và **Hybrid Search (Dense + BM25 + RRF)** để đối soát kết quả.
